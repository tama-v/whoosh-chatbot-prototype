# Lost Items

> Sample document for the Whoosh AI prototype. Not an official operator lost and found service.

## First steps

1. Note the time and the last place the item was seen.
2. Contact station staff or official customer service as soon as possible.
3. Describe the item type, colour, brand, and special features.
4. Keep the ticket number and travel details for verification.

## Information to prepare

- A name and contact number that can be reached.
- Ticket number or booking code.
- Item description and recognisable contents.
- Estimated location: waiting area, gate, train, or station facility.

## Simulated report

The Complaint Assistant in this app can help draft a report with the lost_and_found category. That report is an internal prototype simulation and is not sent to operator staff.
